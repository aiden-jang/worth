# Remember, preferences and workout progress

Worth keeps saved names, actual dated experiences, overall calls and individual
visit reactions separate. All of these views are private and use the existing
owner-scoped archive. They do not require an AI provider, a subscription or a
native companion.

## Log an experience

Open a collection and choose **Log an experience**. Enter a name and save; the
date starts at today. Favorite, Meh and Not again are optional one-tap reactions;
tap the selected reaction again to clear it. **Use a saved name** opens existing
records. **Date and details** opens the date, place, order, note and optional type.
For an existing record, the latest visit on or
before that date shows its saved order and note for reference. Nothing is copied
into the new visit automatically.

The new name and visit save in one database transaction. A lost response keeps
an account-scoped, fixed retry draft; retrying it returns the same saved records.
An altered retry is rejected. Discarding that draft does not undo a save that
already reached Worth. Existing photos can be viewed from history; add or manage
photos through the record and visit details.

The visit reaction never changes the overall call, ranking, Want to try or revisit
queue. Name-only **Keep it** remains available and does not create a visit.

## Find an experience

Open **Remember where you went** from Archive, or **Remember an experience** from
Patterns. Experiences includes explicitly dated collection visits and activity
entries. Search names, notes, visit locations and orders. Date/archive filters
open on demand, or when a link already selects a period. Select a list, date
range or period shortcut; archived lists are opt-in. Records open their original
editor. Results load 50 at a time with an explicit older-records action.

**Saved things** shows when names were first saved, using UTC dates. It does not
claim those dates are visits. Updating an old note does not change that saved date.
Supporting links from preferences retain their exact collection and type/label
filter; clear filters to browse the full archive.

Archive's monthly card counts dated entries whose experience date falls in the
current device-calendar month through today. Its photo or reaction belongs to
its most recent entry. No data, memory or opinion is invented for an empty month.
The card counts entries, so several exercise entries may belong to one workout.

## Read your preferences

Patterns shows up to 12 collection, collection/type or collection/label groups with the most
recorded calls. Collection summaries work without types or labels, including
name-only entries with an explicit visit reaction. Overall-call groups count records; visit-reaction groups count
explicit visits and are labeled separately. Both use current types and labels.
Favorite counts use only rated records or visits in that group as the denominator;
no call stays separate from Meh. Small samples are explicitly identified. Each
group links to its complete, paginated supporting records, including unrated names.
Archived and trashed records are excluded from these summaries.

Favorites with an explicit visit more than 90 days ago can resurface, using the
last logged date rather than assuming you have not visited. Never-visited saved
names are not called old experiences. The cutoff uses the server UTC day.

Repeated visits are a separate observation with their actual Favorite-this-time
count. Frequent visits are not interpreted as enjoyment, and rankings never
produce an inferred call. These are descriptions of currently retained data,
not predictions or historical population estimates. Removing or changing records
changes the summary.

## See workout progress

Quick activity logging needs only a name. Date starts at today; **Date** opens
the date field, and **More details** opens optional measurements and notes. In Exercise mode, **Date and
workout** shows the selected visit and date in its summary. The previous sets
remain an explicit **Use previous sets** action, followed by editable actual
results. Copied sets are not saved until you save the log. Existing or restored
notes open automatically.

Within an activity, **Workout progress** counts explicitly finished sessions in
four- or twelve-week periods and compares the preceding period of equal length.
The weekly list uses seven-day blocks ending today. Active sessions are excluded;
missing entries do not establish that no exercise happened.

Exercise history offers all entries, four weeks or 90 days. Top weight, total reps,
named measurements and complete weighted-set volume remain separate choices.
Volume is weight × reps summed within one exercise entry. It is unavailable if
any set lacks weight or reps; bodyweight is never treated as zero. Kg/lb remain
separate, without conversion. Legacy aggregate entries do not become invented sets.

Best recorded sets are listed by exact rep count and unit, with links to the source
entry. An increase in reps at the same weight is compared with prior entries in
the selected period. Group only genuinely comparable exercise names; different
machines or setups can have different meanings. The chart keeps one equally
spaced point per recorded entry, not an elapsed-time axis or fitness score.

## Design integration

Patterns keeps Remember, Look back and Activity calendar visible, with the other
optional tools in a named disclosure.

The existing cabinet colors, typography, rail and desktop collection composition
remain. Mobile collection selections use a smaller opinion character alongside
the verdict, retaining all three labeled calls and a faceless no-call state.
This is a deliberate compact variation of the original tall mobile reference.
The monthly memory card reuses cream, recorded photos and existing reaction art.
No streaks, social feeds, automatic location tracking or inferred workout targets
are added.
