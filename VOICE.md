# Worth voice

Worth is cute, relaxed and dry. Say less and show the reaction. Use concrete
words such as name, list, note and copy. One small joke per moment is enough.

## Functional language

Primary navigation is Home, Collections and Look back. Signed-in actions use Add item,
Save, Add experience, Edit and Start workout. Inbox is labeled Unfiled in the
primary flow; storage/API names remain unchanged. More tools names the
collection tools. All items, Want to try and Tried are visible collection views;
More filters holds specialized choices. Customize collection contains optional
setup. More from your archive reveals extra Home material. The signed-out example retains Keep it.

Add details opens optional capture fields. Record a dated experience is an
explicit choice; This time labels its reaction, separately from the overall call.
Inline collection capture uses New item options for optional calls and plans;
Call for new item distinguishes those choices from the saved-item filters below.
A name-only find is complete. Never imply that missing details are homework.

Keep account access, workouts, dates, errors, help, privacy, sharing and destructive
confirmations direct. Visibility belongs beside sharing/export/upload decisions,
not in a repeated marketing slogan. Preserve user-written names, descriptions
and notes. Never save brand copy as someone's content.

## Calls and characters

The calls are Favorite, Meh and Not again, plus a separate no-call state. They are
optional, reversible and independent of rank. Meh means an explicit neutral
opinion; it never means someone forgot to choose. Not again maps to the existing
`would_not_again` value. Selecting an active call clears it.

Show one caption for the selected call:

| State     | Caption                           |
| --------- | --------------------------------- |
| Favorite  | Yes, again.                       |
| Meh       | It was a thing.                   |
| Not again | Once was plenty.                  |
| No call   | Undecided. / No opinion required. |

Large characters have matte butter, sage or clay bodies, fine ink features, faint
blush and small rounded feet. Favorite has a pear shape and small warm heart;
Meh slouches and shrugs; Not again leans with a sideways expression. No contrasting
body outline or platform emoji. Compact badges omit limbs and the heart.

Arrival gestures are gentle and finite, with one unhurried blink settling within
3.2 seconds. Only large opinion characters animate; row badges stay still.
Reduced motion disables character animations and hover movement. Choice buttons
retain plain labels, pressed states and visible focus in one inset capsule.
No-call remains faceless and activity logs never acquire personal-call badges.

Humor concerns taste, never bodies, spending, habits or exercise performance.
Avoid motivational praise, streaks, scores, exclamation marks and mascot chatter.
Generic category objects may have decorative faces without implying an opinion.

## Product copy

| Location         | Copy                                                                   |
| ---------------- | ---------------------------------------------------------------------- |
| Landing headline | Your taste. A place to keep it.                                        |
| Supporting line  | Keep what you try. Rank what you like. / The meh can stay.             |
| Signup           | Start your archive →                                                   |
| Landing footer   | Meh is a complete sentence. / Lists for your taste. Logs for the rest. |
| Home             | Good to keep. / Your taste has a paper trail.                          |
| Example capture  | Keep it / Rank later. No rush.                                         |
| Empty collection | Nothing to judge. Yet.                                                 |
| Search start     | Somewhere in here.                                                     |
| No search result | It’s being elusive.                                                    |

Landing topics are Drinks, Midnight snacks and Questionable purchases, with
For research. / Several were necessary. / Seemed reasonable. captions. Keep them
inside the labeled EXAMPLE; they are not starter descriptions to save in accounts.
The running private app uses actual records and useful empty states.

Home reminders say “You liked it. Still on record.”, “Still awaiting its big
moment.” or the actual call for a recent experience. Show another changes the
reminder explicitly. Want to try capture says “Verdict pending. Very reasonable.”
I tried it opens direct call choices; keep its explanation and no-call removal clear.
Unfiled says “Saved. Filing department currently on break.” The idle opinion slip
says “The opinion goes here.” with “Pick an item to see the details or make your
call. Very official.” Capture responses are “A repeat appearance seems likely.”,
“An event occurred.” and “Research concluded.” Only show one call aside at a time;
never replace functional labels or save user content with this copy.
