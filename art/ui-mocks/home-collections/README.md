# Home and collections polish

The approved [interactive reference](index.html) refines Home and the collections
directory within Worth’s existing dark canvas, butter accent and character system.
It owns these screens’ composition; the shared app-wide references still govern
other working pages. Example records are synthetic and save nothing.

- [Home desktop](home-desktop.png) and [phone](home-phone.png).
- [Collections desktop](collections-desktop.png) and [phone](collections-phone.png).

Home has a recent-record index beside a compact vertical collection shelf on
desktop. Cards pair a 72px thumbnail with name and count. Phones stack Recent
before the two-column shelf; a single collection stays horizontal. Recent names
use 18px text with quiet, labeled call badges. The memory panel retains its cream
surface and actual character without a repeated uppercase introduction.

Home and the directory use 36px desktop insets, 28px on narrow desktop and 20px on
phones. Their headings keep the shared 48px / 36px scale with -0.04em tracking.
Directory cards use 144px artwork, 20px gaps and a compact 128px minimum height.
Phone directory artwork remains 96px, or 80px on the narrowest screens.

## Production content and deliberate differences

The running app retains real names, notes, dates, photos, descriptions, counts,
Unfiled access, activity shortcuts, archive/search/order controls and all editing
tools. It never copies this reference’s account, collections or saved names.
Unfiled and activity invitations share a quiet utility row below the Home shelf.
Home keeps its existing recent-record limit and collection limit; phones show all
available preview cards rather than hiding a third example card as this mock does.
The directory retains its real item, rank and Favorite counts.

Home search continues to search the full archive, rather than filtering only the
mock’s recent examples. Its clear action returns focus to the field. The memory
panel retains supporting records, photos, original notes, dates and retry states;
its content and height depend on the saved evidence. Empty accounts keep their
useful invitations. The Home columns continue to stack at 960px for readable real
content. Native phone navigation stays fixed with safe-area clearance.

Collection readers retain their read-only slips, explicit Edit and Add experience
actions, ranking and contextual tools. These existing functions are not removed
to match the simplified preview.
