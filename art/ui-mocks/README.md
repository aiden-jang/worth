# Worth design references

Use these current authored sources in order:

1. [App-wide composition](app-polish/README.md): shared type, spacing, controls and supporting pages.
2. [Collections directory](directory/README.md): compact cards and sparse/filtered states.
3. [Everyday flows](everyday/README.md): lightweight capture, selection, recall and activity.
4. [Taste cabinet](taste-cabinet/README.md): identity, artwork, landing and specialized content.

The [build contract](BUILD-CONTRACT.md) supplies tokens and responsive behavior;
[voice](../../VOICE.md) supplies copy constraints. Later revisions override older
compositions where they overlap.

Representative desktop/phone PNGs remain for the app-wide patterns, sparse directory,
Add and signed-out landing. Other states retain editable HTML; open it at the documented
viewport instead of keeping duplicate renders. All reference data is synthetic.

Compare fresh app captures using [quality checks](../../docs/QUALITY.md). Generated
audit galleries and obsolete explorations remain in Git history rather than the current tree.
