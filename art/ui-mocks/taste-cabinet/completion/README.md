# Settings and product completion reference

The new settings screen follows the accepted cabinet: 192px rail, dark olive,
DM Sans, 68px/50px titles, 28px section headings, quiet rules, 44px controls and
20px phone insets. `settings.html` was authored, rendered and inspected before
building the screen. Open the HTML at 1440 × 900 or 390 × 780 with natural page
scrolling; the app-wide reference governs the current shared title and control scale.

The implementation adds factual backup limits, a restore preview, deletion retention
copy and shared-account/help links. These deliberate content additions lengthen the
page without changing its composition. Existing navigation and its mobile menu remain.
Policies/help use the landing's simple wordmark header, the same type/palette and
one readable text column. Privacy and deletion copy remain factual, with no faces
or jokes beside destructive controls. Follow [quality checks](../../../../docs/QUALITY.md)
for implementation review.
