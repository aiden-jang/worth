# Cabinet identity and creation references

These editable sources define the category-art language and name-first creation
preview. Shared page framing and controls follow the [build contract](../../BUILD-CONTRACT.md).
Primary flows use the [current reference index](../../README.md).

- [Identity sheet](identity.html): palette, character family and authored objects.
- [Creation](create-collection.html): optional description/artwork beside a live preview.
- [Starter choices](starters.html): explicit collection setup, never inserted sample records.

Private uploaded covers take precedence. Automatic artwork uses eligible exact
starter names or monogram slips; explicit artwork selections remain available.
Suggestions fill only the name, without inventing descriptions, calls or records.
The identity sheet is an authored component reference, not a production screen.

View at 1440 × 900 and 390 × 780. Compare implementation captures using
[quality checks](../../../../docs/QUALITY.md). Update these maintained HTML sources
directly rather than regenerating superseded primary-page compositions.
