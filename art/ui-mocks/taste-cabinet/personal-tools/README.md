A deliberate extension of the approved cabinet, for the user's requested custom artwork and gym tracking. These standalone references were rendered and inspected before the UI changes.

- [Artwork desktop](artwork-desktop.png) / [mobile](artwork-mobile.png): six authored objects, automatic fallback, and sage/clay/butter colors. Creation keeps the existing form/live-preview columns. Settings use the same picker within the existing save form.

The final picker labels the door illustration **Place** (the draft said Leaf). Production retains the existing header, navigation, font sizes and draft confirmations. Inputs use readable DM Sans instead of the mock's inherited structural mono. The editor stays a scrolling native dialog, rather than a standalone page. No fixture data goes into a private archive. Blank weight means bodyweight; zero remains a real saved value. Repeating copies measurements with today's date and a blank note. Legacy aggregate measurements remain intact.

Creation initially folds the artwork picker into an optional disclosure, keeping name-only creation short. The reference and selection captures show this disclosure open. It stays open while choosing or resetting artwork. Settings show the picker directly because editing the list's appearance is an explicit task.
