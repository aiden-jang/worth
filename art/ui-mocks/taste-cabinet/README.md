# Worth taste cabinet

The cabinet defines Worth’s identity: dark olive, warm paper, butter accents,
open shelves and one focused opinion slip. Use the [current reference index](../README.md)
for the app-wide, directory and everyday layouts that supersede older compositions.

## Identity and interaction

DM Sans and DM Mono, the existing artwork and labeled call choices form one system.
Favorite, Meh and Not again stay optional, reversible and independent of ranking.
No-call stays faceless. The slip shows the actual call and caption; user-written
names, notes, dates, photos and counts are never invented to fit a reference.

Matte butter, sage and clay characters use fine ink gestures and a small blush.
Finite arrival reactions settle, and reduced motion keeps selection changes immediate.
Functional labels, errors, account access, privacy and destructive actions stay factual.
The [voice guide](../../../VOICE.md) defines humor and copy boundaries.

The current [illustrated landing](landing-cabinet/README.md) retains its desktop/phone
reference pair. The shared [build contract](../BUILD-CONTRACT.md) supplies exact tokens
and responsive rules. HTML compositions load the same [cabinet stylesheet](../../../src/cabinet.css)
as the app; all fixtures are synthetic and save nothing.
