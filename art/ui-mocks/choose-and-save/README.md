# Save and choose

The [editable reference](index.html) owns the compact Add item sheet and the
Choose page. Use `?screen=add` for capture; the default is Choose. All examples
are synthetic. Inspect at 1440 × 900 and 390 × 780.

Capture has one Save action. Name is required; the call, Want to try, short note
and photo are immediately accessible and optional. More details discloses the
destination, collection creation, product context, source tools and an explicit
dated experience. Collapsing it never discards entered information. Existing
retry receipts and recovered drafts remain intact. Activity retains its date.

Choose opens from Home and browses actual saved records across collections and
Unfiled. Search matches recorded text, with one optional collection filter and
All saved / Want to try / Favorites tabs. Cards expose the saved call, plan and
note. This is deliberate browsing of personal records, without invented
recommendations, inferred preferences, outside catalogs or new paid services.

Use the existing shared tokens, native dialogs, real call characters, safe-area
clearance and keyboard behavior. Production retains photo attachment/recovery,
validation, pagination, loading/error/empty states and source links. A photo is
optional and still needs a name; recognition does not silently identify a product.
Collection inline name capture retains its existing behavior in this revision.
