# Worth mock generation — cute visual calls

Generated with the built-in imagegen tool. All five retained outputs were visually inspected for text accuracy, preserved layout, visible call labels, selected Meh state, cute glyph consistency, and readable desktop/mobile composition. Existing versions remain for comparison. These are mock revisions; application code and the decision schema are unchanged.

The cute treatment uses ivory faces, near-black features, tiny dusty-peach cheek marks, soft stroke ends, and occasional small shrug arms. Small read-only glyphs can use an outlined variant. The mobile selected Meh choice includes a tiny shrug as well as the landing. Copy remains Good. Meh. Not again. / It was a thing. / Rank later.

The archive was corrected after its first cute render introduced a Favorite glyph on Morning run. Only the corrected render is retained as the final project file. Activity logs do not gain personal calls from decoration. Existing starter-cover art remains the archive's photo references.
