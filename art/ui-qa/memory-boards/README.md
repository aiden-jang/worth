# Private boards and trip replay QA

The current cabinet build contract governs these secondary pages. The directory
extends Patterns with authored faceless objects, disclosed manual kind/status filters and
dark cards. The native editor uses disclosed source choices, literal dates and
44px controls. A single cream trip ticket is a deliberate new supporting layout;
it preserves the complete readable stop list and explicit Next/Previous controls.
No map, travel-time inference, automatic visit or completion is added.

Reference viewports are 1440 × 900 and 390 × 780. Captures use isolated private
browser fixtures, never production data. The browser journeys also check 320,
430 and 768px, reduced motion, keyboard stop selection, Axe, uncertain saves,
stale review/previous copy, archive/removal, missing sources, missing-board draft
copying, account changes, blocked storage and board-only restore preview.

[Cabinet expansion](../../../docs/CABINET-EXPANSION.md).
