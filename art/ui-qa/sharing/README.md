# Sharing and installed-app details

The collection composition remains the October 10 cabinet edition. The deliberate
addition is a Save ranking image action inside the existing Share dialog. It uses
the same public-field preview as links, with an explicit five-entry image limit.
Image export is independent of creating or revoking a public link. No photos,
notes, calls, dates or history enter the image renderer.

[Desktop dialog](dialog-desktop.jpg) was reviewed with isolated synthetic data at
1440 × 900. The original exported image was inspected with long titles. Phone and
desktop install images were captured from the actual signed-out landing at the
contract viewports and normalized to their encoded image sizes in the manifest.
The Chrome review connection blocked subsequent local artifact navigation, so a
final phone capture of the sharing dialog is unavailable. No private mock fixtures
were added to the production archive.

The workout shortcut uses the existing activity directory and workout editor; it
adds no new visual composition. It creates no records until the person saves.
The privacy and retry tests exercise the image action; a deliberately unfiltered
item object was rejected by the privacy assertion before restoration.

OS install menus, physical phone keyboards, and native email clients were not
verified in this browser review.
