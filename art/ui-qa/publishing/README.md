# Booklets and recommendation cards

The existing cabinet stays underneath the Workbench dialog. Its fourth tool adds
selected-record exports with the same dark controls, warm paper, DM Sans and 44px
targets. Phone tool buttons form two columns. Booklet pages and recommendation
cards are a deliberate extension of the accepted collection composition.

[The actual downloaded PNG](recommendation-card.png) uses synthetic Coffee/Sam
content. Captures are 1440 × 900 and 390 × 780 viewports inside a native scrolling
dialog. No production account was populated. Review checked spacing, contrast,
wrapping, card image resolution and full-text accessibility for the image.

Browser journeys check offline HTML with embedded fonts, content exclusions,
real PNG download, prepared-file invalidation, photo failure/retry, draft recovery
and native-share cancellation. No export sends an API mutation. Axe covers the
booklet tool. Separate synthetic A5 PDFs from both in-app and downloaded HTML
are rendered and inspected page by page; they include only selected content.
This does not verify a physical printer, real phone share sheet or deployment.
