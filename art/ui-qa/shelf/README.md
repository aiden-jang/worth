# Private collection shelves

Your shelf is a fifth Workbench tool. It preserves the underlying cabinet and adds
a secondary private presentation: paper pockets or readable book spines, sage/clay/
butter surfaces, authored arch/plant bookends, a keepsake, dedication and inscription.
The optional faceless folded paper accompanies actual no-call counts. It has no
opinion face and does not assign a call. These are deliberate additions to the
collection reference; name-only capture and the main index stay in place.

Synthetic Coffee/Tea fixtures were captured at 1440 × 900 and 390 × 780 inside the
native scrolling dialog. Each image shows a different scroll position. Review
checked all eight images for wrapping, contrast, spacing and the existing cabinet
palette. Shelf buttons retain 44px targets; long names have no line clamp. Narrow
spines become a single column at 320px. Search and Show more retain access to all
records in creation order, independently of the saved ranking.

Browser journeys cover saved choices after closing, recovering device drafts,
409 conflict recovery with explicit reload, both presentations, search, opening a
keepsake, no-call counts, Axe checks and overflow at 320/390/430/768/1440px. Real D1
tests cover foreign references, revision conflicts, rank/call independence, Trash
hiding/restoration and backup ID remapping. Pure tests reject absent/merged shelf
references and activity shelves in restore files. No live account was populated.

The final production build passed all 87 tests and all 61 browser journeys.
Formatting, lint, unused-code and TypeScript checks passed locally. No GitHub CI
run or deployment is claimed for this unpushed branch.
