# Cover framing and high contrast

The crop dialog keeps the existing dark cabinet styling and adds Reset framing
beside Cancel and Save cover. Zoom shows its current percentage. Reset restores
centered positioning and normal scale without uploading; Cancel preserves the
saved cover. These are secondary editor controls, so the October taste-cabinet
collection layout remains the build reference.

The isolated browser review uses a synthetic three-color image and account.
It checks reset, zoom, saved image pixels, cancellation and narrow widths.
Forced colors use the browser's system palette for fields, selected choices and
keyboard focus. These captures emulate high contrast; physical-device assistive
technology and native autofill remain device checks.
