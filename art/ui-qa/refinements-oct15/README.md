# Cover framing and field details

Cover uploads open a native crop dialog from creation, directory actions, collection
settings and the collection header. Horizontal/vertical position and zoom preview
the same 1.6 crop used for the saved image. Cancel preserves the previous choice;
the server remains authoritative and a failed upload keeps the crop open for retry.

- [Desktop crop](crop-1440.png)
- [Phone crop](crop-390.png)

The October 10 cabinet remains the layout reference. The deliberate addition is a
crop editor using its dark surface, native dialog, butter controls and readable
labels. No collection layout or call semantics change. Browser review uses an
isolated database and a generated two-color image; it checks saved dimensions and
pixels, cancellation, and reflow at desktop, phone, tablet and narrow phone widths.

Native autofill follows the cabinet palette and retains readable selected text.
No private fixtures ship. Physical keyboards and real password-manager autofill
remain device checks.
