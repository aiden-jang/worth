# Collection archiving

The existing cabinet directory gains a 44px Current/Archived choice beneath its
header. The same collection artwork, names, counts and ordering controls remain.
Settings gains a separate Archive collection section before Trash; an archived
collection has a factual banner and an action to open settings. This deliberate
secondary addition preserves the edition directory/collection compositions. The
current empty view says no current collections and points to Archived; it never
claims the whole archive is empty.

Captures use synthetic My drinks/Coffee fixtures at 1440 × 900 and 390 × 780.
The settings capture scrolls to the new reversible action and the separate
deletion area, using the actual desktop/phone viewport.
